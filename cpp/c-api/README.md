# Vista SDK C++ - C API

A C wrapper (hourglass pattern) around the Vista SDK C++ library,
extending its reach to any language capable of linking a C library.

## Build

```bash
cmake -B build -S cpp -DDNV_VISTA_SDK_BUILD_C_API=ON
cmake --build build -j$(nproc)
```

Produces the `dnv-vista-sdk-c` target (CMake alias `dnv::vista::sdk::c`).
Builds as a static library by default; pass `-DBUILD_SHARED_LIBS=ON` for a
shared library (`.so`/`.dll`).

Tests (doctest, mirrors `cpp/tests/`):

```bash
cmake -B build -S cpp -DDNV_VISTA_SDK_BUILD_C_API=ON -DDNV_VISTA_SDK_BUILD_TESTS=ON
cmake --build build -j$(nproc)
ctest --test-dir build
```

## Usage

Single include for the whole C API:

```c
#include <dnv/VistaSDK_c_api.h>
```

Every individual module also has its own header (`dnv/vista/sdk/c/local_id.h`,
`.../decimal.h`, `.../iso19848.h`, etc.) if only part of the surface is needed.

```c
#include <dnv/VistaSDK_c_api_short.h>

#include <stdio.h>

int main(void)
{
    vista_local_id_t* localId = vista_local_id_from_string("/dnv-v2/vis-3-4a/411.1/C101.31-2/meta/qty-temperature/cnt-exhaust.gas");
    if (localId == NULL)
    {
        fprintf(stderr, "parse failed: %s\n", vista_last_error_message());
        return 1;
    }

    const vista_gmod_path_t* primaryItem = vista_local_id_primary_item(localId);
    char* primaryItemStr = vista_gmod_path_to_string(primaryItem);
    printf("Primary item: %s\n", primaryItemStr);
    vista_string_free(primaryItemStr);

    const vista_metadata_tag_t* quantity = vista_local_id_metadata_tag(localId, VISTA_CODEBOOK_NAME_QUANTITY);
    if (quantity != NULL)
    {
        printf("Quantity    : %s\n", vista_metadata_tag_value(quantity));
    }

    vista_local_id_free(localId);
    return 0;
}
```

Output:
```
Primary item: 411.1/C101.31-2
Quantity    : qty-temperature
```

For a larger tour of the C API, see
[`samples/c-api/showcase.c`](../samples/c-api/showcase.c) - VIS, Codebooks,
MetadataTag, Gmod, GmodPath, LocalId, ISO 19848 value validation, VIS
cross-version conversion, GmodPathQuery, LocalIdQuery, and building/
serializing/cross-validating DataChannelList and TimeSeriesData packages:

```bash
cmake -B build -S cpp -DDNV_VISTA_SDK_BUILD_C_API=ON -DDNV_VISTA_SDK_BUILD_SAMPLES=ON
cmake --build build -j$(nproc)
./build/bin/dnv-vista-sdk-sample-c-api-showcase
```

## Conventions

- **Naming**: `dnv_vista_sdk_<module>_<method>`, snake_case. Opaque types:
  `typedef struct dnv_vista_sdk_x dnv_vista_sdk_x_t`. Mirror enums:
  `DNV_VISTA_SDK_<NAME>_<VALUE>`, same numeric values as the source
  `enum class`.
- **Ownership**: each header documents whether its handles are *borrowed*
  (never freed, valid as long as the parent is - e.g. `VIS`/`ISO19848`
  singletons and their direct accessors) or *owned* (returned by value from a
  public C++ constructor or factory, released with a matching `_free`
  function).
- **Errors**: no exceptions cross the ABI. Fallible functions return NULL
  (pointer), 0 (size/bool/index), or `'\0'` (char) on failure, and set a
  thread-local message and kind retrievable via `dnv_vista_sdk_last_error_message()`
  and `dnv_vista_sdk_last_error_kind()` (`error.h`) - the same pattern as `errno`.
  The kind maps 1:1 onto the C++ exception hierarchy (`DNV_VISTA_SDK_ERROR_INVALID_ARGUMENT`,
  `OUT_OF_RANGE`, `DOMAIN`, `OVERFLOW`, `RUNTIME`). Call `dnv_vista_sdk_clear_error()`
  before a fallible operation when a clean slate is required.
- **Strings**: `char*` returned by a `_to_string`/`_from_x` call is owned and
  must be released with `dnv_vista_sdk_string_free` (`common.h`). `const char*`
  returned by a plain getter is borrowed and valid as long as its parent
  handle is.
- **Symbol export**: every function declared in `include/dnv/vista/sdk/c/`
  is annotated `DNV_VISTA_SDK_C_API`, generated by CMake
  (`generate_export_header`) into `Export.h` - the C API's own equivalent of
  the C++ SDK's `DNV_VISTA_SDK_CPP_API`. Required for the functions to stay
  linkable from a shared build (`-DBUILD_SHARED_LIBS=ON`).

## Structure

```
c-api/
├── CMakeLists.txt
├── cmake/
│   └── VistaSDK_c_api_short.h.in  # Template for the opt-in short-alias header
├── include/dnv/
│   ├── vista/sdk/c/               # One header per wrapped C++ module
│   └── VistaSDK_c_api.h           # Umbrella header
└── src/
    ├── cast_internal.h            # All opaque<->C++ conversions, centralized here
    ├── error_internal.h
    └── *.cpp                      # One implementation file per header
```
